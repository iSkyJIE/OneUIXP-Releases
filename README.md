# OneuiXP Releases

这里仅用于发布 **OneuiXP 正式版 APK**、版本说明和校验信息。

- 只提供正式发布版本，不公开 OneuiXP 源代码。
- APK 由 OneuiXP 私有源码仓库的 GitHub Actions 自动构建并使用固定 OWNER SIGNED 证书签名。
- 每个正式版本同时提供 `SHA256SUMS`、`SIGNING_INFO.txt` 和 `APK_PACKAGE_INFO.txt` 供校验。
- OneuiXP 应用内“检查更新”只读取本仓库的 GitHub Releases。

## 下载

请进入本仓库右侧 **Releases**，下载最新版本的：

`OneuiXP_<版本>_BUILD_<构建号>_OWNER_SIGNED.apk`

请勿从非本仓库的第三方来源下载安装包。
