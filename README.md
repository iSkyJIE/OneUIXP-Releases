# OneuiXP Releases

这里仅用于发布 **OneuiXP 正式版 APK** 和版本说明。

- 不公开 OneuiXP 源代码。
- 正式版由 OneuiXP 私有源码仓库的 GitHub Actions 自动构建并使用固定 OWNER SIGNED 证书签名。
- 每个正式 Release 只提供一个 APK 文件。
- OneuiXP 应用内“检查更新”只读取本仓库的 GitHub Releases。

## 下载

请进入本仓库右侧 **Releases**，下载最新正式版：

`OneuiXP_<版本>.apk`

例如：

`OneuiXP_1.0.260930.apk`

请勿从非本仓库的第三方来源下载安装包。
